# UC-08. Утвердить и опубликовать версию

## Актёры

Основной — администратор. Второстепенные — студент и преподаватель, которые получают опубликованное расписание.

## Предусловия

Есть версия в статусе «Готово», у администратора есть право публикации, задан период действия.

## Основной поток

1. Администратор выбирает версию.
2. ScheduleUI вызывает ScheduleService.publishVersion().
3. Сервис проверяет право администратора операцией hasPermission().
4. Сервис повторно проверяет конфликты, покрытие нагрузки и статус.
5. Одной транзакцией прежняя версия уходит в архив, новая получает статус «Опубликовано».
6. Студент и преподаватель видят новое расписание своей группы.

## Альтернативы

- А1. Есть конфликт или непокрытые часы: отказ, статус «Готово» не меняется.
- А2. Нет права публикации: отказ без изменения состояния.
- А3. Сбой транзакции: прежняя опубликованная версия остаётся доступной, операцию можно повторить.

## Постусловия

Версия «Опубликовано» доступна ролям согласно правам, история прошлых версий сохранена.
